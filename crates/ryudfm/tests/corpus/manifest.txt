# The ODB++ corpus: a block per board, `board <name>`, then what it is
# (written by hand) and what it reads to (written by the tests).
#
#   source <text>            who made it, where it came from, what was done
#                            to it (as many lines as it needs; CC-BY's
#                            attribution goes here)
#   licence <SPDX id>        its text in licenses/<id>.txt; `owner` for the
#                            owner's own boards
#   archive <file> <sha256>  the job as an archive in this folder
#   folder <dir>             the same job unpacked, in this folder
#   step <name>              the board step, where the rule can't choose
#   pinned                   fetched and exported by
#                            scripts/fetch-dfm-corpus.sh from pinned.txt,
#                            never committed
#
# The counts after them are tests/corpus.rs's (committed boards) and
# tests/pinned.rs's (pinned ones): `UPDATE_MANIFEST=1` writes them as read.
# Adding a board is docs/claude/ryudfm.md's procedure.
