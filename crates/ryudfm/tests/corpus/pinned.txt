# The KiCad ODB++ corpus: open boards, each pinned to a commit and its board
# file's SHA-256, exported by one KiCad. scripts/fetch-dfm-corpus.sh reads it, and
# tests/pinned.rs checks what it exports against manifest.txt.
#
#   kicad <version>        the `kicad-cli version` every export is made with
#   options <odb options>  passed to every `kicad-cli pcb export odb`
#   commit <name> <repo> <commit> <board> <licence> <sha256>
#       a board whose exports are committed (permissive licences only); the
#       script can make them again to compare (dates aside)
#   fetch <name> <repo> <commit> <board> <licence> <sha256>
#       a board fetched and exported into target/dfm-corpus, never committed
#
# <repo> is a GitHub owner/name; <board> the .kicad_pcb's path in the repo at
# <commit> (no spaces); <licence> an SPDX id, read from the LICENSE file at
# that commit; <sha256> the .kicad_pcb's, which (unlike GitHub's archive) is
# the same bytes for ever.
