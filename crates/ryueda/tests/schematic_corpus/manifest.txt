# The schematic corpus's references: a block per circuit, `circuit <name>`
# (the name tests/schematic_corpus.rs builds it by), then what its
# connectivity follows. Each circuit's script enters the reference's parts
# and connections within the cut its support file's doc comment states;
# the symbols are our own drawings.
#
#   source <text>           who made it, where, at what commit; the cut
#   licence <SPDX id>       the reference's licence, verified at that commit
#   file <path> <sha256>    committed under references/, byte for byte
#                           (only under Apache-2.0, MIT, BSD-3-Clause or
#                           CC-BY-4.0; the project's own licence file and the
#                           README that states it beside it)
#   fetch <url> <sha256>    fetched by scripts/fetch-schematic-refs.sh into
#                           target/schematic-refs/<name>/, never committed
#                           (share-alike or unclear licences)
#
#   crossings <n>           crossings within the cut (plan 1.D's bars,
#                           design 236): counted by eye on the reference's
#                           render (kicad-cli sch export svg, in the
#                           devcontainer) and checked against measure.py's
#                           crossing points inside the cut's box
#   measures <...>          scripts/schematic-refs/measure.py on the whole
#                           file(s), summed: wires, junctions, labels
#                           local/global/hierarchical, power symbols
#                           up/down/sideways; `none` where it can't read
#                           the reference (Eagle)
#
# Measured on cox-worker-2 on 2026-11-03 (plan 1.D's Task 12).
